# ReadFromScratch
Vibecoded Firefox Addon to convert site texts into dictionary links

## Cómo instalarlo
1. Descarga el archivo ZIP y descomprímelo.
2. Abre about:debugging#/runtime/this-firefox en Firefox.
3. Pulsa Cargar complemento temporal….
4. Selecciona el archivo manifest.json de la carpeta descomprimida.
5. Abre cualquier página web, pulsa el icono de la extensión y después Convertir esta página.
